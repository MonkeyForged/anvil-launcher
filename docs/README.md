# Anvil Launcher — User Guide

This guide covers everything you see and do in Anvil: installing it, your first scan, the
window and its navigation, launching and stopping games, saving changes safely, backups,
settings, and the three modules that ship with it — Proton & launch options, Wand Bridge, and
CE Bridge. It does not cover how Anvil is built.

> This guide describes **Anvil 1.3.1**. If you run a different version, some screens may look
> different.

Anvil sets buttons, navigation entries, tags and section labels in capital letters. This guide
quotes them as they are named, not as they are set: `Rescan` is the button that reads
**RESCAN**, `Wand · ready` the tag that reads **WAND · READY**.
